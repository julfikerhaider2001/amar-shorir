# আমার শরীর — Android app

**[⬇️ amar-shorir.apk](amar-shorir.apk)** (51 MB) — built from `main` at commit ae6eee0.

## Install

1. Download `amar-shorir.apk` on the phone (tap the file above, then **View raw** / **Download**).
2. Open it. Android asks to allow installing from this source — allow it.
3. Tap **Install**, then open **আমার শরীর**.

Everything (3D models, pictures, all four Bangladeshi-accent voices) is inside the app, so it works offline.

This is a debug-signed build for sharing with family; it is not on the Play Store.
To build it yourself, see the main branch's README (`npm run android:apk`).
